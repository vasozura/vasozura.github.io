# Salamander Grand Piano samples

These 26 local MP3 files are a reduced, single-velocity-layer set from
**Salamander Grand Piano V3**, a Yamaha C5 recorded by Alexander Holm.

- Source: https://github.com/Tonejs/audio/tree/master/salamander
- Original project: https://archive.org/details/SalamanderGrandPianoV3
- License: Creative Commons Attribution 3.0
- License text: https://creativecommons.org/licenses/by/3.0/
- Modifications in this repository: none

The application loads only the nearest sample roots needed by the active MIDI
or Learning session. Files are self-hosted and are not fetched from a third
party at runtime.
