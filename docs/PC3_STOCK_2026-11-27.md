## Setup

- WanGP revision `f1fcb1e` in `D:\ZuraWork\wan2gp`, with a separate Python 3.11.14 virtual environment and PyTorch 2.10 CUDA 13.0. [WanGP installation instructions](https://github.com/deepbeepmeep/WanGP#manual-installation-for-rtx20xx---rtx50xx)

- The worker targets five seconds of silent 1280 × 720 H.264 at 30 fps. It requires a minute of low GPU utilization and memory use before each render. It resumes from per-clip receipts and retains failed attempts for diagnosis.
- `D:\ZuraWork\stock_clips\metadata.csv` tracks the planned titles, keywords, review status and per-clip timings and sampled GPU memory. `contact.html` adds a first frame as each clip completes. Automated checks cover media format, decode, mostly black clips and probable frontal faces. Review the moving footage for warped geometry, lettering and other visual defects.
