# Catalog onboarding checklist

- [ ] Rights, credits and Georgian/English metadata verified by the owner.
- [ ] Package slug is new, or the exact private draft is approved for resume.
- [ ] Validation-only report has no errors or unknown files.
- [ ] SHA256SUMS matches every package file.
- [ ] Canonical MusicXML/MXL or MIDI is readable.
- [ ] Every enabled instrument has an explicit part.
- [ ] Accordion mapping is versioned and verified; no inferred finger/bellows claims.
- [ ] Import completed as `draft`; no automatic publication occurred.
- [ ] Storage/file checksums and duplicate report reviewed.
- [ ] Learning manifest belongs to the same song and source checksum.
- [ ] Owner preview works on desktop/mobile; anonymous draft access is denied.
- [ ] Publication-readiness checklist passes inside the atomic transaction.
- [ ] Publication is separately and explicitly confirmed.
- [ ] Before/after database and Storage counts are recorded.
